# /research — Documented Research (FAST)

$ARGUMENTS

## Goal

Answer the question with evidence and clear trade-offs.

## Source hierarchy

1. **Runtime truth**: `.venv/` / installed packages (when relevant)
2. **Official docs** (vendor/project)
3. **Authoritative community sources** (issues, RFCs) when needed

## Output

Use `CORE.md` standard sections:

Analisi:
- What you looked at and what you found

Piano:
- If action is requested, propose next steps

Patch:
- N/A unless the user asked to implement

Test:
- N/A unless you implemented

Note:
- Sources (URLs or file paths) and confidence (HIGH/MEDIUM/LOW)
