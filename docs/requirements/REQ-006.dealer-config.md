# REQ-006: Dealer Configuration

## Objective

Enable non-technical admins to configure dealers and shipping policies without modifying code.

## Dealer Definition

File: `providers/dealers.yaml`

```yaml
dealers:
  - key: rms
    name: "RMS"
    type: web
    platform: custom-spa
    base_url_env: DEALER_RMS_BASE_URL
    mapping: providers/web-rms.yaml
    auth:
      mode_env: DEALER_RMS_AUTH_MODE
      username_env: DEALER_RMS_USERNAME
      password_env: DEALER_RMS_PASSWORD
    seeds:
      urls:
        - "https://example.com/category/1"
      sitemap: null
```

## Dealer Fields

| Field | Required | Description |
|-------|----------|-------------|
| key | Yes | Unique identifier (lowercase, no spaces) |
| name | Yes | Display name |
| type | Yes | `web`, `csv`, `api` |
| platform | No | Platform hint (storeden, woocommerce, custom) |
| base_url_env | Yes | Env var containing base URL |
| mapping | Yes | Path to scraping selectors YAML |
| auth | No | Authentication config |
| seeds | Yes | Starting URLs for crawler |

## Shipping Policy (Database)

Table: `dealer_policy`

| Column | Type | Description |
|--------|------|-------------|
| dealer | string | Dealer key (FK) |
| base_cost | float | Base shipping EUR |
| free_threshold | float | Order value for free shipping |
| lead_days_std | int | Standard delivery days |
| updated_at | datetime | Last update |
| source | string | "manual" or "crawled" |

## Admin Operations

| Operation | Method | Persistence |
|-----------|--------|-------------|
| Add dealer | Edit YAML + .env | File |
| Remove dealer | Remove from YAML | File |
| Update shipping | UI or API | Database |
| View status | CLI `dealer-list` | N/A |

## CLI Commands

```bash
# List all configured dealers
uv run python -m app.cli dealer-list

# Show dealer details
uv run python -m app.cli dealer-show rms

# Update shipping policy
uv run python -m app.cli dealer-policy rms --base-cost 8.50 --free-threshold 100
```

## Test Criteria

| Test | Action | Expected |
|------|--------|----------|
| Add dealer | Add entry to YAML | Dealer appears in list |
| Missing env | Add dealer without .env vars | Warning, dealer inactive |
| Update policy | CLI update shipping | New values in DB |
| List dealers | Run dealer-list | All configured dealers shown |
| Invalid YAML | Syntax error in YAML | Startup fails with clear error |
