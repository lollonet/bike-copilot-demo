# REQ-001: Product Search

## Objective

Enable users to find products in the aggregated catalog using multiple search methods.

## Search Methods

| Method | Input | Matching | Example |
|--------|-------|----------|---------|
| Part Number (PN) | Manufacturer code | Exact, case-insensitive | `CS-R8100` |
| EAN | 13-digit barcode | Exact | `4550170894323` |
| Free Text | Keywords | Fuzzy (rapidfuzz) | `shimano ultegra cassette` |
| Category | Dropdown | Exact | `cassette` |

## User Flow

1. User enters search term in input field
2. System detects search type (PN/EAN/text) automatically
3. Results display as table with product info
4. User can apply category filter to narrow results
5. Clicking a product shows available offers (REQ-002)

## API Contract

```
GET /search
  ?q=<search_term>
  &category=<category_name>
  &in_stock=<true|false>
  &limit=<number>

Response: [
  {
    "id": 123,
    "brand": "Shimano",
    "mpn": "CS-R8100",
    "name": "Ultegra Cassette 11-34T",
    "category": "cassette",
    "ean": "4550170894323"
  }
]
```

## Test Criteria

| Test | Input | Expected |
|------|-------|----------|
| PN exact | `CS-R8100` | Single product with mpn=CS-R8100 |
| PN case insensitive | `cs-r8100` | Same result as above |
| EAN lookup | `4550170894323` | Product with matching EAN |
| Fuzzy text | `shimano cassete` (typo) | Products containing "shimano cassette" |
| No results | `xyznonexistent` | Empty array `[]` |
| Category filter | `?q=shimano&category=cassette` | Only cassette products |
