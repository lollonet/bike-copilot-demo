# REQ-008: Quality KPIs

## Objective

Monitor data quality and system health to ensure reliable pricing information.

## Key Performance Indicators

| KPI | Definition | Target | Threshold |
|-----|------------|--------|-----------|
| Freshness | % offers updated in last 24h | >= 85% | Yellow < 85%, Red < 70% |
| Crawl Success | % crawl runs without errors | >= 95% | Yellow < 95%, Red < 80% |
| Coverage | % of searched PNs found in DB | Observe | N/A (informational) |
| Stale Count | Number of offers > 24h old | Minimize | N/A |

## Freshness Calculation

```python
fresh_offers = count(offers where updated_at > now() - 24h)
total_offers = count(all offers)
freshness_pct = (fresh_offers / total_offers) * 100
```

**Note:** Both KPI endpoints require Basic Auth.
