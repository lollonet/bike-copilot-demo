# REQ-003: Order Optimizer

## Objective

Automatically find the best purchasing strategy across multiple dealers, minimizing total cost while respecting constraints.

## Optimization Scenarios

| Scenario | Code | Logic |
|----------|------|-------|
| Best Price | `best-price` | Cheapest offer per item, aggregate shipping |
| Single Dealer | `single-dealer` | All from one dealer if possible |
| Max N Dealers | `max-n-dealers` | Limit to N dealers, minimize cost |
| Fastest | `fastest` | Lowest lead time, price as tiebreaker |

## Cost Calculation

```
total_cost = sum(item_prices) + sum(shipping_costs) + penalties

shipping_cost[dealer] =
  0 if subtotal >= free_threshold
  base_shipping_cost otherwise

penalties =
  penalty_per_extra_dealer * max(0, dealer_count - 1) +
  penalty_per_lead_day * avg_lead_time
```

## Parameters

| Param | Type | Default | Description |
|-------|------|---------|-------------|
| `scenario` | string | `best-price` | Optimization strategy |
| `max_dealers` | int | 3 | Max dealers for `max-n-dealers` |
| `penalty_dealer` | float | 5.0 | EUR penalty per extra dealer |
| `penalty_lead` | float | 0.5 | EUR penalty per avg lead day |

## API Contract

```
POST /optimize
{
  "items": [
    {"product_id": 123, "quantity": 2},
    {"product_id": 456, "quantity": 1}
  ],
  "params": {
    "scenario": "best-price",
    "max_dealers": 3,
    "penalty_dealer": 5.0,
    "penalty_lead": 0.5
  }
}

Response: {
  "total_cost": 245.80,
  "items_cost": 220.00,
  "shipping_cost": 25.80,
  "penalties": 0.00,
  "dealers": ["RMS", "Ciclodiffusione"],
  "lines": [
    {
      "product_id": 123,
      "dealer": "RMS",
      "price": 89.90,
      "quantity": 2,
      "subtotal": 179.80
    }
  ],
  "notes": ["Saved 15.20 EUR vs single-dealer"]
}
```

## Test Criteria

| Test | Setup | Expected |
|------|-------|----------|
| Best price works | 2 items, different best dealers | Items split across dealers |
| Single dealer possible | All items available at one dealer | Single dealer selected |
| Single dealer impossible | Item only at dealer A, another only at B | Fallback to best-price |
| Max 2 dealers | 3 items at 3 dealers | Redistributed to 2 |
| Fastest | Same price, different lead times | Lowest lead time wins |
| Shipping threshold | Subtotal just below threshold | Shipping added |
| Free shipping | Subtotal above threshold | Shipping = 0 |
