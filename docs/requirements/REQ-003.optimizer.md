# REQ-003: Order Optimizer

## Objective

Automatically find the best purchasing strategy across multiple dealers, minimizing total cost while respecting constraints.

## Optimization Scenarios

| Scenario | Code | Logic |
|----------|------|-------|
| Best Price | `miglior-prezzo` | Cheapest offer per item, aggregate shipping |
| Single Dealer | `un-solo-dealer` | All from one dealer if possible |
| Max N Dealers | `max-n-dealer` | Limit to N dealers, minimize cost |
| Fastest | `piu-veloce` | Lowest lead time, price as tiebreaker |

## Cost Calculation

```
total_cost = sum(item_prices) + sum(shipping_costs) + penalties

shipping_cost[dealer] =
  0 if subtotal >= free_threshold
  base_shipping_cost otherwise

penalties =
  penalty_per_extra_dealer * max(0, dealer_count - 1) +
  penalty_per_lead_day * avg_lead_time
```

## Parameters

| Param | Type | Default | Description |
|-------|------|---------|-------------|
| `scenario` | string | `miglior-prezzo` | Optimization strategy |
| `max_dealer` | int | null | Max dealers for `max-n-dealer` |
| `penale_dealer` | float | 3.5 | EUR penalty per extra dealer |
| `penale_lead` | float | 0.5 | EUR penalty per avg lead day |

## API Contract

```
POST /optimize
Content-Type: application/json

Request (OptimizeRequest):
{
  "items": [
    {"maker_pn": "CS-R8100", "qty": 2},
    {"maker_pn": "RT-CL800", "qty": 1, "locked_dealer": "rms"}
  ],
  "params": {
    "scenario": "miglior-prezzo",
    "max_dealer": 3,
    "penale_dealer": 3.5,
    "penale_lead": 0.5
  }
}

Response (OptimizeResponse):
{
  "lines": [
    {
      "offer_id": 123,
      "maker_pn": "CS-R8100",
      "name": "Ultegra Cassette",
      "dealer": "rms",
      "unit_price": 89.90,
      "qty": 2,
      "line_total": 179.80,
      "lead_time_days": 3
    }
  ],
  "dealers": ["rms", "b2bike"],
  "costs": {
    "subtotal": 220.00,
    "shipping": 25.80,
    "penalties": 3.50,
    "total": 249.30
  }
}
```

## Test Criteria

| Test | Setup | Expected |
|------|-------|----------|
| Best price works | 2 items, different best dealers | Items split across dealers |
| Single dealer possible | All items available at one dealer | Single dealer selected |
| Single dealer impossible | Item only at dealer A, another only at B | Fallback to best-price |
| Max 2 dealers | 3 items at 3 dealers | Redistributed to 2 |
| Fastest | Same price, different lead times | Lowest lead time wins |
| Shipping threshold | Subtotal just below threshold | Shipping added |
| Free shipping | Subtotal above threshold | Shipping = 0 |
