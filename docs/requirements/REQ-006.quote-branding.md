# REQ-006 — Branding preventivi

Obiettivo
- Rendere i preventivi professionali e riconoscibili con logo negozio e intestazione cliente.

Ambito
- Impostazioni: logo, nome negozio, contatti, indirizzo, IVA di default.
- Quote: intestazione cliente (nome/azienda, contatto), validità giorni, note.
- Output: HTML sempre; PDF se `wkhtmltopdf` è presente; numerazione file `QUOTE-YYYYMMDD-HHMM`.
