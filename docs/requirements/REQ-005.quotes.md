# REQ-005: Quote Generation

## Objective

Generate professional, branded quotes from cart contents for presentation to end customers.

## Quote Structure

### Header
- Shop logo (PNG/JPG, max 500KB)
- Shop name, address, contact, VAT number
- Quote number and date
- Validity period

### Customer Section
- Customer name / company
- Contact info (optional)

### Line Items Table
| PN | Description | Dealer | Unit Price | Qty | Subtotal |
|----|-------------|--------|------------|-----|----------|

### Totals Section
- Items subtotal
- Shipping (per dealer breakdown)
- Grand total
- VAT note (if applicable)

### Footer
- Validity statement
- Terms and conditions (optional)
- Notes field

## Output Formats

| Format | Requirement | Fallback |
|--------|-------------|----------|
| HTML | Always generated | N/A |
| PDF | If wkhtmltopdf installed | HTML only |

## File Naming

```
QUOTE-{YYYYMMDD}-{HHMM}.html
QUOTE-{YYYYMMDD}-{HHMM}.pdf

Example: QUOTE-20251219-1430.pdf
```

## Configuration

| Setting | Type | Default |
|---------|------|---------|
| Shop name | string | Required |
| Shop logo | file path | Optional |
| Shop address | string | Optional |
| Shop VAT | string | Optional |
| Validity days | int | 7 |
| Default notes | string | Empty |

## API Contract

```
POST /quote
{
  "customer": {
    "name": "Bike Shop Roma",
    "contact": "mario@bikeshop.it"
  },
  "validity_days": 7,
  "notes": "Delivery in 5 working days",
  "format": "pdf"
}

Response: {
  "quote_id": "QUOTE-20251219-1430",
  "html_path": "/out/QUOTE-20251219-1430.html",
  "pdf_path": "/out/QUOTE-20251219-1430.pdf",
  "valid_until": "2025-12-26"
}
```

## Test Criteria

| Test | Setup | Expected |
|------|-------|----------|
| HTML always | Any cart | HTML file created |
| PDF with tool | wkhtmltopdf installed | PDF file created |
| PDF without tool | wkhtmltopdf missing | HTML only, no error |
| Logo included | Logo configured | Logo visible in output |
| No logo | Logo not configured | No logo, no error |
| Validity | 7 days configured | "Valid until" shows +7 days |
| Unique ID | Generate twice same minute | Different IDs (add seconds) |
