# REQ-007: Data Crawling

## Objective

Automatically fetch product and pricing data from dealer websites, keeping the local database fresh.

## Crawl Strategy

| Site Type | Tool | Detection |
|-----------|------|-----------|
| Static HTML | httpx + BeautifulSoup | No JS required |
| SPA/JS | Playwright | JavaScript rendering needed |
| API | httpx | Direct API integration |

## Crawl Flow

```
1. Load dealer config from YAML
2. Authenticate if required (login flow)
3. Fetch seed URLs
4. For each page:
   a. Extract product data using selectors
   b. Rate limit (wait configurable delay)
   c. Follow pagination
5. Upsert products to database
6. Record price changes
7. Log results
```

## Scheduling

| Mode | Trigger | Use Case |
|------|---------|----------|
| Cron | System cron/scheduler | Production |
| Manual | CLI command | Testing/on-demand |
| On-startup | App startup flag | Development |

Recommended: Daily at 3:00 AM local time

## Rate Limiting

| Parameter | Default | Description |
|-----------|---------|-------------|
| delay_seconds | 2 | Wait between requests |
| max_concurrent | 1 | Parallel requests (1 = sequential) |
| retry_count | 3 | Retries on failure |
| retry_backoff | 2.0 | Exponential backoff multiplier |

## Data Mapping

Selectors defined in `providers/web-{dealer}.yaml`:

```yaml
selectors:
  product_list: ".product-card"
  product_link: "a.product-link"
  detail:
    name: "h1.product-title"
    price: "meta[property='og:price:amount']"
    mpn: ".sku-value"
    ean: ".ean-value"
    stock: ".availability-status"
    category: "#breadcrumb li:last-child"
pagination:
  next: "a.next-page"
  mode: link  # or 'query' for ?page=N
```

## CLI Commands

```bash
# Crawl single dealer
uv run python -m app.cli crawl rms --limit 100

# Crawl all dealers
uv run python -m app.cli crawl-all

# Dry run (no database writes)
uv run python -m app.cli crawl rms --dry-run

# Resume failed crawl
uv run python -m app.cli crawl rms --resume
```

## Error Handling

| Error | Action | Logged |
|-------|--------|--------|
| Network timeout | Retry with backoff | Warning |
| 404 Not Found | Skip, continue | Info |
| 403 Forbidden | Stop dealer, alert | Error |
| Parse error | Skip product, continue | Warning |
| Auth failure | Stop dealer, alert | Critical |

## Test Criteria

| Test | Setup | Expected |
|------|-------|----------|
| Fresh crawl | Empty DB, run crawl | Products inserted |
| Update crawl | Existing products | Updated_at changed |
| Price change | Product with new price | Price history recorded |
| Rate limit | Crawl 10 pages | ~20s total (2s delay) |
| Retry | Simulate 1 failure | Success on retry |
| Parse error | Invalid selector | Skip product, continue |
