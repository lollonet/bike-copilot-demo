# REQ-007 — Gestione dealer e policy spedizioni

Obiettivo
- Gestire un registro dealer (configurazione, credenziali opzionali) e le politiche di spedizione/soglie per ottimizzare i costi.

Ambito
- Dealer registry: base_url, piattaforma, mapping selettori, politiche crawling, attivazione.
- Credenziali: none/basic/form/token; storage sicuro (.env/secret file) e test login.
- Policy extractor: estrazione deterministica di `base_cost`, `free_threshold`, `lead_days_std` + override manuale.
