# REQ-002: Offers Display

## Objective

Display all available offers for a product, enabling price comparison across dealers.

## Offer Information

| Field | Description | Format |
|-------|-------------|--------|
| Dealer | Supplier name | String |
| Price | Net B2B price | Currency (EUR) |
| Stock | Availability | Boolean (icon) |
| Lead Time | Delivery days | Integer or N/A |
| Shipping | Threshold for free shipping | Currency or "Free > X" |
| Updated | Last crawl timestamp | Relative time |

## Display Rules

1. **Sort**: By price ascending (cheapest first)
2. **Highlight**: Best price row gets visual emphasis
3. **Stale warning**: Offers older than 24h show warning icon
4. **Out of stock**: Shown but visually dimmed

## User Flow

1. User searches for product (REQ-001)
2. Clicks on product row
3. System shows offers table
4. User selects dealer and clicks "Add to Cart"
5. Item added to cart (REQ-004)

## API Contract

```
GET /products/{product_id}/offers

Response: [
  {
    "id": 456,
    "dealer": "RMS",
    "price": 89.90,
    "currency": "EUR",
    "in_stock": true,
    "lead_time_days": 2,
    "updated_at": "2025-12-19T08:00:00Z"
  }
]
```

## Test Criteria

| Test | Setup | Expected |
|------|-------|----------|
| Multiple offers | Product with 3 dealer offers | All 3 displayed, sorted by price |
| Single offer | Product with 1 offer | Single row, still highlighted as best |
| No offers | Product with no offers | Empty state message |
| Stale offer | Offer updated 48h ago | Warning icon visible |
| Mixed stock | 2 in stock, 1 out | Out of stock dimmed |
