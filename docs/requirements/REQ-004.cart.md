# REQ-004: Shopping Cart

## Objective

Manage a multi-dealer shopping cart that accumulates items before generating a quote.

## Cart Structure

| Field | Description |
|-------|-------------|
| Product ID | Reference to product |
| Product Name | Display name |
| MPN | Part number |
| Dealer | Selected supplier |
| Unit Price | Price per unit |
| Quantity | Number of units |
| Subtotal | Unit price * quantity |

## Cart Operations

| Operation | Trigger | Effect |
|-----------|---------|--------|
| Add | Click "Add to Cart" on offer | New line or increment qty |
| Update Qty | Edit quantity field | Recalculate subtotal |
| Remove | Click X on line | Remove line |
| Clear | Click "Clear Cart" | Empty cart |
| Apply Plan | Click "Apply" after optimize | Replace cart with plan |

## User Flow

1. Search product (REQ-001)
2. View offers (REQ-002)
3. Select dealer, set quantity, click "Add to Cart"
4. Repeat for more items
5. Review cart
6. Optionally run optimizer (REQ-003)
7. Apply optimized plan or keep manual selection
8. Generate quote (REQ-005)

## Cart Totals

```
items_total = sum(line.subtotal for line in cart)
shipping_estimate = sum(dealer_shipping for dealer in unique_dealers)
grand_total = items_total + shipping_estimate
```

## Persistence

- **Client-side**: localStorage with JSON serialization
- **Server-side**: Session-based (if multi-device needed)
- **Duration**: Until explicitly cleared or browser data cleared

## Test Criteria

| Test | Action | Expected |
|------|--------|----------|
| Add first item | Add product to empty cart | Cart shows 1 item |
| Add same product | Add same product+dealer | Quantity incremented |
| Add different dealer | Same product, different dealer | Separate line |
| Update quantity | Change qty from 1 to 3 | Subtotal = price * 3 |
| Remove item | Click remove | Item gone, totals updated |
| Apply optimizer | Run optimize, apply | Cart replaced with plan |
| Clear cart | Click clear | Cart empty |
| Persistence | Refresh page | Cart still populated |
