# ARC-010: System Overview

## Context

Bike Copilot is a local-first B2B price aggregation system for bike shops. It runs on the shop's PC, crawls dealer websites overnight, and provides a web UI for searching products, comparing prices, and generating quotes.

## Component Responsibilities

| Component | Responsibility | Key Files |
|-----------|---------------|-----------|
| Web UI | User interface, search, cart, quotes | `app/templates/`, HTMX partials |
| REST API | HTTP endpoints, request validation | `app/api.py` |
| CLI | Admin commands, crawl triggers | `app/cli.py` |
| Search | Product lookup, fuzzy matching | `app/search.py` |
| Optimizer | Order optimization algorithms | `app/optimizer.py` |
| Quote | Quote generation, PDF rendering | `app/quote.py` |
| Crawl | Web scraping, data ingestion | `app/adapters/`, `app/ingest.py` |
| Data | ORM models, database access | `app/models.py` |

## Data Flow

### Search Flow
```
User → UI → API(/search) → SearchService → SQLite → Results → UI
```

### Optimization Flow
```
Cart → API(/optimize) → OptimizerService → DealerPolicy → Plan → UI
```

### Quote Flow
```
Cart → API(/quote) → QuoteService → Jinja2 → HTML → [wkhtmltopdf] → PDF
```

### Crawl Flow
```
Scheduler → CLI(crawl) → CrawlService → Playwright/httpx → Parse → Upsert → SQLite
```

## Deployment Model

### Local Installation (Current)

```
Shop PC (Windows/Mac/Linux)
├── Python 3.12 + uv
├── SQLite database (data/bike.db)
├── Output files (out/)
└── FastAPI server (localhost:8000)
```

### Startup
```bash
uv run python -m app.cli api  # Start API server
# Browser opens to http://localhost:8000
```

### Scheduled Crawl
```bash
# Cron job or Task Scheduler
0 3 * * * cd /path/to/app && uv run python -m app.cli crawl-all
```

## Quality Attributes

| Attribute | Approach |
|-----------|----------|
| Reliability | SQLite WAL mode, idempotent upserts |
| Performance | Local DB, no network latency for queries |
| Maintainability | Typed Python, Pydantic validation |
| Portability | Single folder, no external DB server |
